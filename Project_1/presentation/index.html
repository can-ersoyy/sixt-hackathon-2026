Problem Statement & Objective

Teach a Machine to Say "I Don't Know"

High-Precision Document Extraction Under 100:1 Asymmetric Error Cost

⚠️ The Real-World Asymmetric Dilemma

In business-critical workflows (contracts, vehicle handover forms, damage reports, invoices), an automated false answer is catastrophic:

Manual Human Review
Cost = 1
Operator verifies in 30 sec
Accepted Error / Hallucination
Cost = 100
Disputes, compliance audits
Mathematical Breakeven Rule: To achieve positive ROI, automated precision must exceed 99.01% ($P > \frac{100}{101}$). Standard 95% NLP models lose money rapidly!

🎯 Our Architectural Strategy

Instead of forcing a model to guess every field, our system is engineered to know when it is right and confidently abstain otherwise.

1. Layout-Aware Canonical Indexing
Documents parsed into hierarchical Node Trees ([sec-X/p-Y/s-Z]) enabling token-saving location citations.
2. Adaptive Modality Routing
VLM page rendering for noisy scans & checkboxes; deep sliding-window text for 100+ page contracts.
3. Dual-LLM Consensus & Subtree Grounding
Cross-model consensus gate + strict verbatim & fuzzy grounding against node text eliminates hallucinations.

Structural Grounding

Hierarchical Node Tree & Canonical Addressing

Layout-Aware Structural Indexing with Token-Saving Location-Only Citations

[sec-1] MASTER LEASE AGREEMENT ├── [sec-1/p-1] PARTIES & JURISDICTION │ ├── [sec-1/p-1/s-1] "This Master Lease entered by SIXT Rent-a-Car..." │ └── [sec-1/p-1/s-2] "Governed under the laws of Germany." └── [sec-1/p-2] INDEMNIFICATION CLAUSE └── [sec-1/p-2/s-1] "Customer liability is capped at EUR 1,000." [sec-2/table-0] PRICING & TAX SCHEDULE ├── [sec-2/table-0/row-1] Base Daily Rental Rate | EUR 85.00 └── [sec-2/table-0/row-2] Applicable VAT (19%) | EUR 16.15
Every sentence, table row, and form box receives a permanent hierarchical address path.

💡 Location-Only Evidence Optimization

Instead of generating verbose 100-word text quotes in LLM responses:

{
  "value": "Germany",
  "evidence_span": "[sec-1/p-1/s-2]"
}
⚡ Saves ~70% of generation tokens & cuts latency by over 2.5x!

🔍 Deterministic Subtree Grounding

The verifier never searches full 50-page text blindly. It calls:

parsed.get_node_with_neighbors("[sec-1/p-1/s-2]")

Fetches the exact sentence plus immediate siblings to handle cross-boundary spans in milliseconds.

Modality Architecture

Adaptive Modality Routing & Schema Chunking

Dynamically Tailoring Model Modality and Schema Granularity to Document Archetypes

🔀 Adaptive Router (`router.py`)

Heterogeneous document collections require specialized modality pipelines:

Multimodal VLM Branch
Trigger: scanned_pdf, image, or digital_pdf ≤ 5 pages.
Renders 150 DPI page images via PyMuPDF. Preserves checkboxes ([X]), stamps, tables, and handwritten signatures.
Text Node Tree Branch
Trigger: Long legal contracts (CUAD) or > 5 pages.
Section-based sliding window up to 180,000 characters with 5,000 char overlap, eliminating 60k truncation blindness.

📦 Schema Chunking for Dense Forms

ExtractBench forms contain 50 to 150+ properties. Single prompts drop fields due to output token exhaustion.

// Dynamic Async Schema Partitioning
Dense Schema (80 fields)
  ├── Chunk 1 (Fields 01-20) ──► Worker 1 (Async)
  ├── Chunk 2 (Fields 21-40) ──► Worker 2 (Async)
  ├── Chunk 3 (Fields 41-60) ──► Worker 3 (Async)
  └── Chunk 4 (Fields 61-80) ──► Worker 4 (Async)
Merge Dicts & Deduplicate ──► Clean Unified Output
Guarantees zero missed fields on complex IRS/customs declaration forms.
Zero-Hallucination Verification

Dual-Model Consensus & Grounding Verifiers

Multi-Tier Defense Against False Positives: Consensus Gate, Subtree Verifier & Arithmetic Sanity

👥 Fast-Path Dual-LLM Consensus

Pass 1 (Primary Model):
  ├─ says null ──► Abstain (Cost: 1, 0 extra tokens)
  └─ says "Germany" [sec-1/p-1]
        │
        ▼
Pass 2 (Independent Model / Modality):
  ├─ Disagree ──► Conf = 0.0 (Route to Human)
  └─ Agree    ──► Proceed to Subtree Verifiers

Null fields never trigger Pass 2, saving 60%+ of verification token expenditure!

🛡️ Grounding Verifiers (`verifiers.py`)

Subtree Fuzzy Alignment:
Extracted value must match target node text with partial_ratio ≥ 75.
Tri-State Checkbox Logic:
"false" (blank box) is valid without quote citations; null reserved for absent sections.
Financial Arithmetic Guardrail:
Enforces $|(\text{Subtotal} + \text{Tax} - \text{Discount}) - \text{Total}| \le 0.02$ on invoices.
Official Normalizers:
Reuses 5_score.py normalizers (norm_amount, norm_date, norm_id).
Core Architecture Rule: Only fields that pass both independent model consensus and spatial subtree grounding achieve confidence $\ge 0.95$. All ambiguous fields safely default to human review.
